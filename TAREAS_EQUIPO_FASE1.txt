1. TAREAS PARA DIEGO: MODELOS ELOQUENT Y RELACIONES
--------------------------------------------------------------------------------
Objetivo: Representar cada tabla con su modelo Eloquent en app/Models/, definir
sus relaciones bidireccionales, sus propiedades $fillable y $casts, e incluir
las etiquetas [ENCAPSULAMIENTO] y [RELACION].

Archivos a crear/modificar:
a) app/Models/Categoria.php
   - Crear con: php artisan make:model Categoria
   - $fillable = ['nombre', 'descripcion', 'activo']; // [ENCAPSULAMIENTO]
   - $casts = ['activo' => 'boolean'];
   - Relación con Platillo:
     public function platillos() // [RELACION]
     {
         return $this->hasMany(Platillo::class);
     }

b) app/Models/Platillo.php
   - Crear con: php artisan make:model Platillo
   - $fillable = [
         'categoria_id', 'nombre', 'descripcion', 'precio',
         'tiempo_preparacion', 'disponible', 'imagen'
     ]; // [ENCAPSULAMIENTO]
   - $casts = [
         'precio' => 'decimal:2',
         'tiempo_preparacion' => 'integer',
         'disponible' => 'boolean',
     ];
   - Relaciones:
     public function categoria() // [RELACION]
     {
         return $this->belongsTo(Categoria::class);
     }
     public function detallePedidos() // [RELACION]
     {
         return $this->hasMany(DetallePedido::class);
     }
     public function pedidos() // [RELACION]
     {
         return $this->belongsToMany(Pedido::class, 'detalle_pedidos')
                     ->withPivot('cantidad', 'precio_unitario', 'subtotal')
                     ->withTimestamps();
     }

c) app/Models/Pedido.php
   - Crear con: php artisan make:model Pedido
   - $fillable = ['codigo', 'cliente', 'mesa', 'fecha', 'estado', 'total', 'notas']; // [ENCAPSULAMIENTO]
   - $casts = [
         'fecha' => 'datetime',
         'mesa' => 'integer',
         'total' => 'decimal:2',
     ];
   - Relaciones:
     public function detalles() // [RELACION]
     {
         return $this->hasMany(DetallePedido::class);
     }
     public function platillos() // [RELACION]
     {
         return $this->belongsToMany(Platillo::class, 'detalle_pedidos')
                     ->withPivot('cantidad', 'precio_unitario', 'subtotal')
                     ->withTimestamps();
     }

d) app/Models/DetallePedido.php
   - Crear con: php artisan make:model DetallePedido
   - $fillable = ['pedido_id', 'platillo_id', 'cantidad', 'precio_unitario', 'subtotal']; // [ENCAPSULAMIENTO]
   - $casts = [
         'cantidad' => 'integer',
         'precio_unitario' => 'decimal:2',
         'subtotal' => 'decimal:2',
     ];
   - Relaciones:
     public function pedido() // [RELACION]
     {
         return $this->belongsTo(Pedido::class);
     }
     public function platillo() // [RELACION]
     {
         return $this->belongsTo(Platillo::class);
     }

Commits sugeridos para Diego (cumple los 3 commits obligatorios):

RESUMEN DE COMANDOS PARA INICIAR EL PROYECTO CADA INTEGRANTE
