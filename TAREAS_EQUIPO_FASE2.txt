1. TAREAS PARA DIEGO: MÓDULO DE PEDIDOS Y DETALLE (ENTIDAD RELACIONADA)
--------------------------------------------------------------------------------
Objetivo: Implementar el controlador de pedidos (PedidoController), la lógica de
cálculo en el servidor de subtotales y total, la transacción en base de datos
y las acciones de consulta y cambio de estado.

Archivos a crear/modificar:
a) app/Http/Controllers/PedidoController.php
   - Crear con: php artisan make:controller PedidoController
   - Métodos a implementar:
     * index(Request $request):
       Listado paginado de pedidos con carga anticipada ('platillos', 'detalles').
       Permitir filtrar por estado (pendiente, en_preparacion, servido, pagado, cancelado).
       Etiqueta: // [CRUD-READ]
     * create():
       Formulario para nuevo pedido. Enviar platillos disponibles:
       $platillos = Platillo::where('disponible', true)->with('categoria')->orderBy('nombre')->get();
     * store(StorePedidoRequest $request):
       // [CRUD-CREATE] [SEGURIDAD] [REGLA-NEGOCIO]
       IMPORTANTE: Los precios, subtotales y el total se calculan estrictamente
       en el servidor con Eloquent/DB Transaction:
       
       use Illuminate\Support\Facades\DB;
       
       DB::transaction(function () use ($request) {
           $total = 0;
           $detallesData = [];
           
           // Generar codigo unico, ej: PED-2026-001 o con Str::upper(Str::random(6))
           $ultimoId = Pedido::max('id') ?? 0;
           $codigo = 'PED-' . str_pad($ultimoId + 1, 4, '0', STR_PAD_LEFT);
           
           $pedido = Pedido::create([
               'codigo' => $codigo,
               'cliente' => $request->cliente,
               'mesa' => $request->mesa,
               'fecha' => now(),
               'estado' => 'pendiente',
               'total' => 0, // Se actualiza al final
               'notas' => $request->notas,
           ]);
           
           foreach ($request->platillos as $linea) {
               $platillo = Platillo::findOrFail($linea['platillo_id']);
               
               // [REGLA-NEGOCIO] No agregar platillos no disponibles
               if (!$platillo->disponible) {
                   throw new \Exception("El platillo {$platillo->nombre} está agotado.");
               }
               
               $cantidad = (int) $linea['cantidad'];
               $precioUnitario = $platillo->precio; // Congelado al momento del pedido
               $subtotal = $cantidad * $precioUnitario;
               $total += $subtotal;
               
               DetallePedido::create([
                   'pedido_id' => $pedido->id,
                   'platillo_id' => $platillo->id,
                   'cantidad' => $cantidad,
                   'precio_unitario' => $precioUnitario,
                   'subtotal' => $subtotal,
               ]);
           }
           
           // Actualizar total general calculado en backend
           $pedido->update(['total' => $total]);
       });
       
       return redirect()->route('pedidos.index')->with('exito', 'Pedido registrado correctamente.');
     * show(Pedido $pedido):
       // [CRUD-READ] Vista de Ticket del pedido con sus detalles y platillos cargados.
       $pedido->load(['detalles.platillo.categoria']);
       return view('pedidos.show', compact('pedido'));
     * updateEstado(Request $request, Pedido $pedido):
       // [CRUD-UPDATE]
       $request->validate(['estado' => 'required|in:pendiente,en_preparacion,servido,pagado,cancelado']);
       $pedido->update(['estado' => $request->estado]);
       return back()->with('exito', 'Estado del pedido actualizado.');
